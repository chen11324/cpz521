# 同频回声 Empathy Circle

同频回声是一个跨端生活分享应用原型。用户可以匿名或实名发布生活片段，由同频用户和多个 AI 智能体提供情绪反馈，同时通过 AI 审核、人工复核和安全网关降低广告、诈骗、违法内容和攻击风险。

## 本轮已实现

- 本地 API：新增 Node HTTP 服务，支持 SQLite 结构化持久化。
- API 优先：前端会优先调用 `http://localhost:8787/api`，失败时自动回退到浏览器本地模式。
- 发布流程：用户可选择匿名或实名，发布后立即进入 AI 风控判断。
- AI 回声：通过审核的动态会生成三个智能体回复，覆盖情绪陪伴、价值澄清和行动支持。
- 同频反馈：通过审核的动态会生成同频用户回应，模拟圈层推荐后的正向评论。
- 审核队列：高风险、危机关键词和用户举报会自动进入人工审核面板。
- 人工处理：审核员可以对任务执行通过、拒绝、升级，动态状态会同步更新。
- 举报闭环：用户可举报动态，举报会增加动态举报数并创建待审任务。
- 安全看板：展示 WAF、隐私隔离、内容拦截、DDoS 模拟拦截等安全事件。
- 圈层页面：提供同频圈层展示和加入动作，为后续推荐算法预留入口。
- 智能体页面：展示 AI 智能体角色定位和反馈策略。
- PWA 能力：包含 manifest 和 Service Worker，可作为网站或可安装 Web App 运行。

## 演示账号与权限

- 普通用户：`user` / `User@123`，登录后进入用户端，可匿名或实名发布动态。
- 内容审核员：`reviewer` / `Review@123`，进入管理台，可处理审核队列。
- 运营管理员：`operator` / `Operate@123`，可处理审核并查看账号权限。
- 最高管理员：`superadmin` / `Admin@123`，拥有全部后台权限，可配置 AI 服务接口。
- 第三方登录：微信支持扫码或快捷登录演示，QQ 和 Apple 支持快捷登录演示，首次进入都需要绑定 11 位手机号。
## 本地运行

只启动前端：

```bash
npm install
npm run dev
```

同时启动前端和本地 API：

```bash
npm run dev:full
```

默认访问地址：`http://localhost:5173`

本地 API 地址：`http://localhost:8787/api/state`

## 当前技术边界

当前版本已经具备本地全栈 MVP：前端、API 服务和 SQLite 数据库持久化都可运行。AI 服务配置支持 DeepSeek/OpenAI Compatible 接口连通测试；未填写密钥时会回退到本地规则，便于离线演示。它还不是生产级后端，暂未接入真实账号系统、数据库集群、云 WAF 和正式应用商店打包流程。

## DeepSeek 测试

最高管理员登录后进入 `AI 服务`，推荐配置：

- 服务商：`DeepSeek`
- 接口地址：`https://api.deepseek.com/v1`
- 模型：`deepseek-chat`
- API Key：可在界面临时填写，服务端仅保留运行期密钥和掩码展示

点击 `测试分析审核` 会调用 `/api/admin/ai-test`，完成情绪分析与内容审核测试。也可以通过环境变量启动：

```powershell
$env:DEEPSEEK_API_KEY='你的密钥'; npm run dev:api
```

本地数据库文件：`data/empathy-circle.sqlite`

## 推荐后端模块

- 用户服务：手机号、邮箱、第三方登录、实名身份、匿名身份池。
- 动态服务：发布、删除、可见性、圈层分发、媒体附件、举报统计。
- 评论服务：同频用户评论、AI 评论、评论审核、互动计数。
- AI 服务：情绪识别、价值倾向分析、正向反馈生成、危机识别、广告诈骗识别。
- 审核服务：AI 初筛、人工复核、升级处理、申诉、审核日志。
- 风控服务：IP 限流、设备指纹、异常行为检测、DDoS/WAF 事件入库。
- 通知服务：审核结果、AI 回复、同频评论、危机干预提醒。

详细接口草案见 `docs/api-contract.md`。

## 跨平台路线

### PWA 网站

- 当前代码已经支持 Web 端和移动浏览器响应式布局。
- 可部署到 CDN，并通过 HTTPS 支持安装到桌面或手机主屏幕。

### Windows/macOS 软件

- 使用 Tauri 封装当前前端，输出 Windows `.msi/.exe` 和 macOS `.dmg`。
- 桌面端建议增加系统通知、本地加密缓存、自动更新和托盘入口。

### Android/iOS App

- 使用 Capacitor 封装当前前端，输出 Android Studio 和 Xcode 项目。
- 移动端建议增加推送通知、相册选择、相机权限、系统分享和生物识别。

四端打包步骤和验收清单见 `docs/cross-platform-checklist.md`。

## 安全设计

- 网络防护：CDN + WAF + Anycast 清洗 + 网关限流。
- 账号防护：验证码、登录风控、设备指纹、异常登录提醒。
- 内容防护：文本敏感词、语义分类、URL 检测、图片 OCR、视频抽帧审核。
- 隐私防护：TLS 传输、敏感字段加密、匿名身份与真实账号隔离。
- 审核合规：审核日志、申诉通道、未成年人保护、危机干预流程。
